# Prompt Specification — Kroma (`kroma-agy`)

> Master prompt derived from Viktor Oddy's reference (`vision-reveal`), adapted for Kroma.

```text
Build a single self-contained index.html file for a creative studio showcase called "Kroma". No build step, no external CSS/JS libraries.

1. Animations:
- Staggered mechanical shutter aperture splash screen (10 blue tiles sliding up and down).
- Hero image entrance with scale and subtle rotation settle.
- Word-reveal headline with progressive blur unmasking.
- Interactive canvas spotlight reveal layer tracking the mouse position with dynamic mask-image gradient.
- Slide-in glassmorphic dark mobile/desktop menu with social links and contact trigger.
- Expanding hover background pill CTA button with arrow circle.
```
