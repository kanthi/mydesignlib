# Vellox — Design System & Architectural Blueprint

> **Rebrand Source**: Derived from Farhan Rizzvi Sales SaaS reference (`@farhanrizzvi` on X / Twitter status `2104800858235978103` — Salesflow)
> **Identity**: **Vellox** (`vellox`) — *Boost Your Sales Team's Performance*
> **Category**: `Sales` / `SaaS`

---

## 1. Brand Philosophy & Identity

- **The Problem**: Sales pipelines stall when account reps are bogged down in fragmented CRM manual updates, disconnected payment data, and blind handoffs.
- **The Value Prop**: Vellox provides autonomous pipeline intelligence, automated deal stage routing, and live KPI telemetry that turns leads into closed revenue with zero friction.
- **Visual Personality**: Warm enterprise clarity. Crisp off-white surfaces, vibrant stacked-bar KPI data visualizations in refreshing greens and corals, punctuated by a radiant, optimistic butter-yellow accent hero section.

## 3. Typography Hierarchy

- **Primary Display**: `Plus Jakarta Sans` / `Inter` (weights 400, 600, 700, 800) with `-0.03em` tight tracking.
- **Metrics & Numbers**: Bold numerals with clear tabular layout.

---

## 4. Key Interactive Components

1. **Dual Hero Dashboard Cards**:
   - `Delivery Status` card: segmented horizontal bar with hoverable status segments (In-Transit, Delivered, Delayed).
   - `Key Performance Indicator` card: 5-month stacked bar chart with interactive tooltip recalculations.
2. **Interactive Bills & Payments Automation Table**:
   - Filterable transaction table (All Active, Bills, Subscription, Income, Transfer) with real-time status chips.
3. **Radiant Yellow Statement Section**:
   - 4 high-impact quantitative counters: **75%** productivity lift, **40%** faster closures, **50+** automated stages, **24/7** support.
4. **App Integration Ecosystem Grid**:
   - 16 custom SVG ecosystem integration tiles with interactive hover reveals.
5. **Interactive Demo Modal & Newsletter Lead Capture**.
