# Alveor Website Template — Design Prompt & Reference

Derived from the SaaS landing page design by Mehedi (`@MehediHnux`) on X:
`https://x.com/MehediHnux/status/2106688087715934638`

Rebranded as **Alveor** (AI Personal Knowledge Engine & Second Brain for Everything You Think, Build and Decide).

## Core Design Directives
- **Palette**: Crisp white canvas (`#FFFFFF` / `#FAFAFA`), deep charcoal text (`#111827`), soft muted slate headline words (`#94A3B8`), and signature warm coral/terracotta textured gradients (`#F9AE84` to `#EE7A47`).
- **Typography**: Clean modern sans-serif (`Plus Jakarta Sans`) with high-contrast two-tone display headlines.
- **Components**:
  - Full-fidelity macOS SaaS workspace mockup with sidebar navigation, document editor, rich toolbar, and comment thread.
  - 4-card Frictions problem breakdown.
  - 5-cell Bento Feature Matrix with knowledge graph nodes, integration hub, and conversational search.
  - Interactive 3-tier Pricing matrix with monthly/yearly billing toggle.
  - Expandable FAQ accordion.
  - Warm coral textured CTA banner.
  - Giant translucent watermarked wordmark `Alveor` at the bottom of the footer.
