# DESIGN — Keyway (Model Context Protocol Gateway & Security Proxy)

## Overview
- **Audience**: AI engineers, enterprise security leads, CISOs, and platform developers deploying AI agents and LLM tool architectures with the Model Context Protocol (MCP).
- **Single CTA**: `Deploy Gateway` (with secondary `Book a demo` / `Explore Docs`).
- **Emotion**: Absolute architectural confidence, crisp enterprise clarity, zero tool sprawl anxiety.
- **Create this feeling through**:
  - High-clarity luminous backdrop (`#fafafa`) with hairline schematic grid lines (`rgba(0, 0, 0, 0.04)`).
  - Controlled dual-color signal accents: Deep Electric Indigo (`#4f46e5`) for protocol conduits, and Security Emerald (`#10b981`) for verified authorization packets.
  - Interactive SVG & Canvas conduit motion: animated packets traveling from client agent nodes through the central Keyway Gateway Door into remote tool servers.
  - High-precision typography: Clean geometric grotesque (`Plus Jakarta Sans`) paired with technical monospace (`JetBrains Mono`).

## Source of truth
- This file + CSS `:root` in `index.html`.

## Aesthetic commitment
- **Name**: Modern Technical Zero-Trust
- **Signature element**: The Central Controlled Gateway Door Conduit — an interactive circuit diagram with real-time packet pulses, schema policy inspection, and live tool authorization telemetry.

- `text-muted`: `#94a3b8` — Subtle labels, wireframe lines, inactive nodes

- `action-primary-hover`: `#1e293b` — Hover dark slate
- `signal-indigo`: `#4f46e5` — Protocol conduits, client agent badges, active tabs
- `signal-emerald`: `#10b981` — Verified tool call packets, healthy status beacons

## Typography
- **Display**: `Plus Jakarta Sans`, sans-serif (Weights: 600, 700, 800) — Hero headings, section titles
- **Body**: `Inter`, sans-serif (Weights: 400, 500) — Explanatory copy, docs, specs
- **Mono / Telemetry**: `JetBrains Mono`, monospace (Weights: 400, 500, 600) — Code snippets, JSON schemas, packet coordinates
- **Scale**:
  - Hero display: `clamp(2.75rem, 5.5vw, 4.75rem)` (leading: 1.05, tracking: -0.03em)
  - Section title: `clamp(2.0rem, 3.8vw, 3.0rem)` (leading: 1.15, tracking: -0.02em)
  - Card title: `1.25rem` (leading: 1.3)
  - Body: `1.0rem` (leading: 1.6)
  - Code / Pill: `0.78rem` (tracking: 0.02em)

## Layout & Structure
1. **Header**:
   - Fixed white glassmorphic navbar with keyway slot brandmark, navigation links (`Product`, `Docs`, `Security`, `Ecosystem`, `Pricing`), and `Book a demo` / `Try for free` action buttons.
2. **Hero Stage & Interactive Gateway Conduit**:
   - Headline lockup: `Every agent. Every tool. One door.`
   - Subhead: `Policy, security, and authorization gateway for your Model Context Protocol (MCP) ecosystem. Less sprawl. Better agents. Zero surprises.`
   - Dual CTAs: `Try for free` and `Book a demo`.
   - **Interactive Live Conduit Schematic**:
     - Left: Client Agent Nodes (Claude Desktop, Cursor, LangChain, Python Agent, AutoGen).
     - Center: The **Keyway Gateway Door** (The single controlled security checkpoint with policy evaluator, PII scrubber, and session signer).
     - Right: MCP Tool Servers (PostgreSQL, GitHub, Stripe, AWS, Slack, Linear).
     - Animated 60fps packet pulses traveling across circuit lines with live payload inspection drawer.
     - Interactive mode switcher: `STRICT MODE (BLOCK UNKNOWN)` vs `AUDIT PROXY` vs `AIRGAP ENFORCEMENT`.
3. **Telemetry Proof Strip**:
   - Real-time metrics: `2.4ms` avg proxy latency, `100%` MCP Spec v1.2 compliance, `0` PII data leaks, `48,000+` tool invocations filtered.
4. **Three Core Security Pillars**:
   - 1. *Zero-Trust Tool Gating*: Granular schema-level permissions and rate limits.
   - 2. *Automated PII & Secret Redaction*: Real-time masking of API keys, credit cards, and customer data before LLM tool call dispatch.
   - 3. *Cryptographic Audit Trail*: Immutable provenance records of every parameter sent, executed, or rejected.
5. **Interactive Policy Builder (Live Simulator)**:
   - Real-time YAML/JSON policy configuration tester where users can toggle rules and watch tool calls get allowed or blocked instantly.
6. **MCP Ecosystem Directory**:
   - Filterable catalog of supported MCP clients and servers.
7. **Enterprise Security & Compliance Matrix**:
   - SOC 2 Type II, HIPAA, ISO 27001, and GDPR controls.
8. **Transparent Tiered Pricing**:
   - Developer (Free & Open Source Core), Team ($29/seat/mo), Enterprise (Dedicated VPC / On-Premise Airgap).
9. **Frequently Asked Questions**:
   - Accordion answering latency overhead, MCP version compatibility, self-hosting options, and prompt injection defenses.
10. **Pre-Footer CTA & Clean Minimalist Footer**:
    - Ready to secure your MCP ecosystem with zero search indexing and Google Analytics.
