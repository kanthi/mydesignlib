Enterprise Security Foundations

Built for the agentic tool sprawl reality

AI models with direct database access, third-party APIs, and terminal execution are catastrophic liabilities without strict perimeter controls.

Zero-Trust Tool Gating

Granular schema enforcement. Ensure an agent can only query permitted tables and invoke approved methods. Block arbitrary destructive mutations like DROP TABLE or unhedged deletes.

// Policy: postgresql_rules.yaml
allow_methods: ["SELECT"]
deny_methods: ["DROP", "TRUNCATE"]
max_row_limit: 250

Common Questions

Everything you need to know

How does Keyway intercept MCP calls without breaking the protocol? ↓
Keyway acts as a standard JSON-RPC 2.0 proxy compliant with the Anthropic Model Context Protocol specification. It exposes standard stdio and SSE (Server-Sent Events) interfaces that clients connect to directly. Keyway inspects, redacts, and authorizes payload messages before forwarding them to downstream tool servers.
Does Keyway store or transmit prompt payloads to third parties? ↓
No. Keyway operates with zero telemetry exfiltration. In the developer edition and enterprise self-hosted distribution, all traffic remains strictly inside your local host or private VPC perimeter. Cryptographic hashes are generated locally.
Can I define custom regex rules and argument validators? ↓
Yes. Keyway policies are authored in standard YAML or JSON. You can configure granular path matching, JSON schema parameter validations, regex token masking, rate limits, and custom failure handling (e.g. return synthetic tool error vs drop packet).
What is the latency overhead when running in production? ↓
Keyway's proxy engine is engineered in Go and Rust using zero-allocation streaming parsers. Median latency overhead is 1.8 milliseconds, which is negligible compared to typical LLM inference times (500ms - 2,500ms).
