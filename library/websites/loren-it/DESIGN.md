# DESIGN — Loren IT (Modern High-Reliability Infrastructure & Platform Architecture)

## Overview
- **Brand**: Loren IT
- **Positioning**: High-reliability platform and infrastructure engineering firm. Scope: cloud architecture & migration, platform engineering/DevOps, data center & bare-metal compute, low-latency network & zero-trust security, managed operations (24/7 NOC/SRE). Explicitly non-SAP, non-BPO, non-staffing.
- **Audience**: Technical evaluators (Principal Architects, Platform Leads, VP Infrastructure, CTOs, compliance auditors).
- **Core Value Proposition**: Deterministic engineering, zero marketing fluff, concrete SLAs, reproducible infrastructure-as-code, and audit-ready compliance.
- **Primary Action**: Direct mailto link (`mailto:architecture@loren-it.example`).

## Visual Design System & Upgrades
- **Palette**:
  - `bg-base`: `#f6f8fa` (Cool Precision Paper Canvas)
  - `bg-surface`: `#ffffff` (Pure White Content Panels with subtle micro-elevation)
  - `bg-subtle`: `#edf1f5`
  - `bg-dark`: `#0f1217` (Terminal Console / Dark Hardware Panels)
  - `text-primary`: `#14171d` (Deep Graphite)
  - `text-secondary`: `#495261` (Engineered Slate)
  - `text-muted`: `#788292` (Mortar Gray)
  - `accent-teal`: `#0c7275` (Deep Technical Teal — live status indicators, code anchors, interactive states)
  - `accent-teal-dark`: `#085456`
  - `accent-teal-soft`: `rgba(12, 114, 117, 0.08)`
  - `accent-teal-glow`: `rgba(12, 114, 117, 0.22)`
  - `border-hairline`: rgba(20, 23, 29, 0.10)
  - `border-focus`: rgba(12, 114, 117, 0.40)
- **Imagery & Visual Assets**:
  - **Hero Server Hardware Imagery**: High-resolution server rack cabling and dark hardware array with interactive telemetry coordinates overlay.
  - **Practice Area Photography & Schematics**: Real server hardware wiring, global network satellite mesh, and SRE operations center imagery accompanying technical practices.
  - **Interactive Live Telemetry Strip**: Animated pulsing live operational beacon, auto-refreshing telemetry timestamps, and dynamic metric ticker.
- **Micro-Interactions & Transitions**:
  - Smooth card hover lift with hairline border intensification (`transform: translateY(-3px); box-shadow: 0 12px 32px rgba(15, 18, 23, 0.06)`).
  - Clean CSS keyframe animations for status beacon pulse and telemetry transitions.
  - Tabbed interactive practice switcher and expandable case study architecture drawers.
- **Typography**:
  - `font-sans`: `IBM Plex Sans`, -apple-system, BlinkMacSystemFont, sans-serif
  - `font-mono`: `IBM Plex Mono`, SFMono-Regular, Menlo, monospace (metrics, latencies, SLAs, uptime, terminal commands)
