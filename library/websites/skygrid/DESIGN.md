# Skygrid — Design System

## Vision & Brand Identity
Skygrid is an ultra-fast distributed cloud mesh network. The visual identity features a saturated electric cyan-blue backdrop (#0066ff), high-contrast white sans typography, crisp 3D isometric data node networks, and floating midnight navy pill controls.

## Color Palette
- Canvas Background: `#0066ff` (Vibrant Electric Sky Blue)
- Dark Accent / CTA Pill: `#060b18` (Midnight Navy Black)
- Card Surface: `rgba(255, 255, 255, 0.12)` with `1px solid rgba(255, 255, 255, 0.25)`
- Text Primary: `#ffffff`
- Text Soft: `rgba(255, 255, 255, 0.85)`

## Typography
- Display & Body: `Plus Jakarta Sans`, `Inter`, sans-serif
- Code: `JetBrains Mono`, monospace

## Core Layout & Components
1. **Header & Navigation**: Brand emblem with dark midnight navy floating `Menu ::` pill button.
2. **Hero Section**: Electric blue background with bold white headline "Intelligence that builds what's next", subhead, dark navy CTA button ("Book a Call ↗"), crisp isometric 3D glowing data network illustration.
3. **Trust Bar**: Partner logo wall.
4. **Interactive Node Telemetry Dashboard**: Live node latency simulator with real-time throughput metrics.
5. **Developer Code Playground**: Tabbed SDK code snippets.
6. **Tiered Pricing & Booking System**.
