# Rebuild Prompt — PopZero

Create a production-grade, minimalist DTC beverage website hero for **PopZero**.

## Requirements
1. **Brand Identity**:
   - Brand name: "PopZero".
   - Theme: Dark matte minimalist aesthetic with a dynamic ambient radial glow that transforms colors across three flavors:
     1. Zero Lime (`#22c55e`)
     2. Diet Classic (`#ef4444`)
     3. Pure Berry (`#a855f7`)
   - Typography using `Plus Jakarta Sans` and `Space Grotesk`.

2. **3D Can & Repulsion Physics Engine**:
   - Centered Three.js 3D beverage can with brushed metallic rims, embossed wordmark, pull-tab, and smooth cursor drag/tilt tracking.
   - Floating fruit berries and carbonation bubbles orbiting the can that scatter away with radial repulsion physics when the mouse approaches.
   - Right-side stacked flavor pills (`Zero Lime / $2.99`, `Diet Classic / $2.99`, `Pure Berry / $2.99`) that dynamically redraw the can wrap, adjust Three.js studio lights, and update background glow.

3. **Layout**:
   - Header: `@ PopZero` brand circle icon, center links (`Ingredients`, `Taste`, `Eco`, `Reviews`), right `Contact Us`.
   - Left Hero: "Unleash the crisp taste of zero sugar. Refreshment redefined in every bubble — all in one sleek design." with pill "Shop Now →" button.
   - Footer: "★ DESIGN AWARDS / PREMIUM BEVERAGE 2025".

4. **Compliance & Constraints**:
   - Pure vanilla HTML/CSS/JS without npm/build dependencies.
   - No search indexing meta tags (`robots` and `googlebot` noindex).
   - Google Analytics gtag `G-Z97ZD3EVSF` in `<head>`.
