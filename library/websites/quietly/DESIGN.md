# DESIGN — Quietly

## Overview
- Audience: Privacy-conscious product & growth teams
- Single CTA: Start free trial
- Emotion: Calm clarity — “analytics without surveillance”
- Create this feeling through:
  - Vast white space; one soft indigo accent
  - Centered thesis headline (two short lines)
  - Product dashboard as the hero proof
  - Floating benefit chips, not feature card grids
  - Monochrome logo strip for trust

## Aesthetic commitment
- Name: Soft clean SaaS (privacy analytics)
- Signature: Soft indigo ambient glow cradling a light product window

## Colors
- paper: `#FFFFFF` / `#FAFBFC`
- ink: `#0F172A`
- muted: `#64748B`
- line: `#E2E8F0`
- accent: `#5B5BD6` (soft indigo — product vernacular, not generic #6366F1 gradient hero)
- accent-soft: `#EEF0FF` / glow `#E4E7FF`
- success: `#16A34A` · danger: `#DC2626` (deltas only)

## Typography
- Display/body: Plus Jakarta Sans
- H1: clamp 2.5–3.5rem, weight 700, tracking −0.03em, centered
- Body: 1.05rem, muted, max ~42ch

## Layout
### Compact
- Nav collapses to logo + menu; stack CTAs; dashboard scrolls horizontally if needed
### Expanded
- Centered hero column; full product stage; logo strip

## Components
- Pill nav CTA outline + filled primary
- Annotation chips around product frame
- Metric row with green/red deltas
- Soft area chart (SVG)

## Ban
- Real analytics brands (Plausible etc.)
- Inter, purple mesh gradients as full-page background, 3 equal feature cards as only content
- Emoji icons, dense marketing sections above the product

## Source
Craft distilled from clean SaaS landing pattern (UXRishi share, 2026-08-12) — structure only, original brand.
