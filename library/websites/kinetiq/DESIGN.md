# Kinetiq Design System Specification

> High-craft creative technologist and generative frontend portfolio template directly matching the architecture, palette, motion language, and visual craft of the Run Rob Run / Codrops WebGPU 3D Audio-Reactive Goo reference.

---

## 1. Overview & Visual Aesthetic

### Audience & Tone
- **Audience:** Design studios, visionary creative directors, technology brands, and digital agencies seeking cutting-edge creative development and WebGL/WebGPU 3D craft.
- **Palette & Mood:** Editorial warm concrete off-white (`#dbdbda`) base canvas, ultra-high contrast graphite black (`#202020`) typography, explosive electric cadmium orange (`#ff641c`) core and pixel matrix accents.
- **Emotional Hook:** Tactile, musical, and alive. Physical mass with asymmetric damping physics, real Web Audio synthesis, 300vh scroll-driven 3D blob-to-cube morph, and 8x8 pixel grid matrix reveals.

## 3. Layout Hierarchy & Sections

1. **Global Chrome:**
   - 6 Technical corner crosses (`tl`, `tr`, `tc`, `bl`, `br`, `bc`).
   - Grain canvas overlay (`.site-noise-layer`).
   - 10x8 pixel loader with animated wireframe runner mark.
   - Interactive cursor orb (`.cursor-orb`).
   - 6-column orange pixel section transition overlay (`.section-scroll-transition`).
2. **Topbar Navigation:**
   - `KINETIQ` brand mark.
   - Nav links (`About`, `Tools`, `Work`, `Let's create`) with interactive 44-cell pixel matrix hover animations.
3. **Hero Stage (300vh Track with Sticky 100dvh 3D Scene):**
   - Monumental display titles: `Creative` at top, `Developer` at bottom right.
   - Location ticker carousel (`London`, `Tokyo`, `Berlin`, `New York`, `Remote`).
   - Bio copy paragraph on the bottom left.
   - Attached Web Audio player: track timeline line, orange puck, play toggle, "PRESS PLAY" button, and 3-track playlist.
   - Central 3D Goo: Clear refractive outer shell + electric orange core deforming in real time to audio frequencies.
4. **Page Entry Split Manifesto:**
   - Left: `Thoughtful ideas shaped with meaning`.
   - Right: `Bold systems built to hold attention`.

7. **Work Showcase:**
