# Kalyx Network — Design System & Spec

> Modular ZK-Rollup Layer 2 Infrastructure.

---

## 1. Brand Identity & Vision

- **Brand Name**: Kalyx
- **Descriptor**: High-Throughput Modular ZK-Rollup
- **Core Value**: The Next [Evolution] of Modular Scalability.
- **Visual Motif**: Carbon void, neon persimmon / coral accents (`#ff5733`), architectural bracket framing (`┌ ┐ └ ┘`), dot matrix telemetry grid, and high-density financial crypto console UI.

---

## 2. Color System

- **Background Void**: `#0a0b10` (carbon black)
- **Console Surface**: `#11131c`
- **Border Subtle**: `rgba(255, 255, 255, 0.08)`
- **Accent Coral / Persimmon**: `#ff5733`
- **Accent Coral Glow**: `rgba(255, 87, 51, 0.25)`
- **Success Mint**: `#10b981` (telemetry live status)
- **Text Main**: `#f8fafc`
- **Text Muted**: `#94a3b8`

---

## 3. Typography

- **Headings & Display**: 'Space Grotesk', 'Plus Jakarta Sans', sans-serif
- **Telemetry, Code & Brackets**: 'JetBrains Mono', monospace

---

## 4. Key Interactive Components

1. **Architectural Bracket Framing**:
   - Custom CSS corner brackets (`┌ ┐ └ ┘`) highlighting key headings, metric chips, and console cards.
2. **Interactive Kalyx L2 Dashboard Console**:
   - Web3 wallet summary with dynamic balance.
   - Interactive instant bridge simulator with 3-stage cryptographic progress animation (`01 Proving -> 02 Batching -> 03 L1 Settlement`).
   - Live TPS & gas telemetry feed.
3. **6-Stage Scalability Engine**:
   - Modular breakdown of transaction lifecycle from EVM opcode execution to recursive ZK proving.
4. **Network Telemetry Counter**:
   - Real-time simulated metrics (TPS, block time, gas cost).
5. **Technical FAQ & CLI Quickstart**:
   - One-click copy for `npx kalyx-cli deploy`.
