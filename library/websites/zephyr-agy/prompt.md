# Prompt Specification — Zephyr (`zephyr-agy`)

> Master prompt derived from Viktor Oddy's reference (`email-landing-page`), adapted for Zephyr.

```text
Build a premium, AI-native email client landing page called "Zephyr" using React 18 + TypeScript + Vite + Tailwind CSS + lucide-react. The aesthetic is dark (bg #0c0c0c), cinematic, glassy, with a looping fullscreen background video, a shiny gradient headline, a macOS-style menu bar, a realistic inbox mockup, and a custom "liquid-glass" card treatment.

## Stack & Setup
- React 18 + TypeScript + Vite + Tailwind CSS 3 + Lucide Icons
- Background color base #0c0c0c, text white, selection bg-brand/30
- Fixed full-screen looping video background:
  https://d8j0ntlcm91z4.cloudfront.net/user_38xzZboKViGWJOttwIXH07lWA1P/hf_20260508_064122_c4750c0e-7476-4b44-94a2-a85a65c63bf2.mp4
  Poster: ./assets/poster.jpg
- Two fixed vertical guideline rules at 36rem container edges

## Sections
1. Navbar: LogoMark + Zephyr, links (Solutions, Features, Triage, Pricing, Documentation), Download Zephyr for Mac button.
2. Hero: "Your email." / "Revitalized" (with shiny text animation), context copy, and macOS download CTA.
3. macOS Menu Bar Strip: Apple mark, Zephyr, File/Edit/View menus, live clock & search.
4. Inbox Mockup: Complete macOS client window with traffic lights, sidebar (Compose with Zephyr, Mailboxes, Smart Folders), interactive message list with real threads, and Reader panel with "Summary by Zephyr" AI breakdown.
5. Feature Triage: Two-column grid with AI-native triage breakdown: Priority (4), Follow-up (7), Updates (18), Archived (13).
6. Testimonials: 3 liquid-glass cards from engineering leaders.
7. Pricing: Starter ($0), Pro Tier ($16/mo), Enterprise ($28/seat).
8. Footer: Copyright and legal navigation links.
```
