# Straton — Design System & Architecture Specification

> **Rebrand Source**: Derived from Aakib autonomous AI workflow machine design reference (`@1Aakib` on X / Twitter status `2104680267525075047` — Native). Rebranded completely as **Straton** (Straton AI / Straton Systems).

---

## 1. Brand Concept & Strategic Position

**Straton** is an enterprise autonomous operations platform that moves critical, complex business workflows from manual human bottlenecks into deterministic, self-healing AI agent pipelines. It embeds directly inside legacy and modern stacks (Slack, Salesforce, Jira, NetSuite, AWS, Linear) to handle exceptions, customer orders, logistics delays, financial reconciliation, and outbound intelligence in real time.

- **Primary Persona**: VP of Engineering, Chief Operating Officer, Head of Product & Automation.
- **Brand Archetype**: Architectural, Deterministic, Ethereal Precision, Calm Power.
- **Tone**: Understated authority, zero-fluff, enterprise-grade stability.

## 4. Key Components & Interactive Features

1. **Precision Hairline Header**:
   - Monolithic geometric Straton vector mark (stepped geometric polygon).
   - Navigation links with vertical hairline divider columns: `What We Build`, `How We Work`, `Case Studies`, `About`.
   - Dark pill CTA button: `Let's Talk →`.

2. **Panoramic Ethereal Alpine Hero**:
   - Rich cinematic misty alpine mountain & lake reflection scenery frame.
   - Dual-card glassmorphic interactive operations hub:
     - **Card A (Left — Workflow Progress)**: Real-time event log for order delay exception with live chronological pulse indicators (Issue detected → AI agent analysing → Logistics updated → Customer notified → Finance synced → Resolution completed).
     - **Card B (Right — Autonomous Agent Chat)**: Live conversational stream with AI reasoning snippets, message dispatch history, and interactive prompt field allowing users to test query simulation.

3. **Client Proof Row**:
   - Monochrome high-contrast SVG vector marks: Stripe, Topgolf, n8n, AWS, JPMorgan, Salesforce, Datadog.

4. **6-Card Interactive Bento Grid ("Give every repetitive workflow a way to run itself")**:
   - **Follow-ups**: Dynamic notification stack with automated triage chip and outbound dispatch note.
   - **Records**: Isometric database wireframe topology with glowing synchronization nodes.
   - **Workflows**: Multi-app isometric interconnected pipeline (Linear, Notion, Figma, Slack) converging on automated publication.
   - **Intelligence**: Document OCR visualizer with parsed tabular invoice metadata card (`ACME Inc`, `$1,200`, `INV-1042`).
   - **Finance**: Dynamic date selector pills and instant reconciliation verification badges.
   - **Execution**: Lead qualification status trigger with multichannel dispatch icons.

5. **Interactive Operations ROI Simulator**:
   - Real-time slider calculating weekly human hours saved, exception turnaround reduction, and annual ROI.

6. **Enterprise Security & Compliance Grid**:
   - SOC2 Type II, ISO 27001, HIPAA, and Zero Data Retention guarantee.

7. **Transparent Tiered Pricing**:
   - Interactive monthly/annual billing switcher with savings badge.

8. **Comprehensive FAQ & Conversion Banner**:
   - Accordion interaction with crisp answers to technical deployment questions.
