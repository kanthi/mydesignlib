SUBTLE KINETIC TYPOGRAPHY // 01
SPECIMEN NO. 04 // EDITORIAL MOTION

Subtle text animations can make a simple page feel special.

// EDITORIAL CONVICTION

We believe typography should breathe before it speaks. In a modern web landscape saturated with aggressive motion, the quietest transitions command the deepest focus.

// THE 4 PRIMITIVES

Whisper-Quiet Typography Primitives

01 // CHARACTER STAGGER

Damped Letter Rise

Each character lifts from a masked clipping boundary with exponential spring easing. Zero layout shift.

Crafting quiet spaces.
02 // FOCUS ROLL

Blur-to-Focus Dissolve

Words emerge from a gentle 10px Gaussian haze into crisp editorial ink on scroll progression.

Focus where it matters most.
03 // UNDERLINE TRACE

Hairline Velocity Scrub

Precision SVG stroke drawn along the typographic baseline, calibrated to user reading pace.

A statement that endures.
04 // MASKED LIFT

Dual-Line Slip

Multi-line editorial phrases slip out of baseline masks with staggered micro-delays.

Delivered when it matters most.

/* Pure CSS Zero-Layout-Shift Mask */
.char-wrap {
  display: inline-block;
  overflow: hidden;
  vertical-align: bottom;
}

.char-inner {
  display: inline-block;
  animation: charLift 0.65s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}

@keyframes charLift {
  0% {
    transform: translateY(115%);
    opacity: 0;
  }
  100% {
    transform: translateY(0%);
    opacity: 1;
  }
}
