Frequently Asked Questions

How does this differ from video-frame scrolling? +
Video-frame scrolling scrubs pre-rendered image sequences, which consume dozens of megabytes, cannot react to the mouse cursor in real-time, and suffer from temporal compression artifacts. Fluxion is 100% real-time mathematical WebGL: lightweight, resolution-independent, and fully interactive.
Does it run smoothly on mobile devices? +
Yes. The simulation utilizes GPU point buffer instancing and dynamically scales the pixel ratio and particle attenuation based on the client hardware, maintaining 60 FPS on modern iOS and Android devices.
Can custom 3D geometries and logos be imported? +
Absolutely. Any 3D model (.obj / .gltf) or vector SVG path can be parsed into an array of vertex coordinates, allowing the particle cloud to morph cleanly into custom client logos and product silhouettes.
