# Flowstack — Website Design & Prompt Reference

## Prompt Concept
A clean, restrained product homepage where the product UI sits in front of a procedurally generated pixel-dithered desert backdrop. Real HTML/CSS app preview with interactive drag-and-drop mechanics, WebGL dune fragment shader backdrop, GSAP + ScrollTrigger + Lenis motion, three theme presets (Default, Night, Glacier), and zero build step.

## Visual Characteristics
- **Color Palette**: Obsidian Ink (#0F1115), Ember Terracotta (#E86F3B), Sand Cream (#F6F5F2), Deep Slate (#1B1F27), Glacier Blue (#3B82F6).
- **Hero Staging**: Layered product-as-proof application staging with a custom fragment shader generating procedural desert dunes behind the app interface.
- **Typography**: Archivo (Display), Inter (Interface & UI).
- **Distinctive Elements**: Procedural WebGL dithered dune simulation with fallback PNG states, interactive application workspace with task cards and team chat, plain language automation rule builder, live theme switching.
