# DESIGN — Rastera (Reactive Pixel Matrix & Motion Primitives)

## Overview
- **Audience**: Creative technologists, frontend engineers, design engineers, and motion designers seeking cutting-edge procedural text effects and lightweight canvas motion primitives.
- **Single CTA**: `Copy Component` / `Explore Presets` (secondary: `View Docs` / `npm install rastera`).
- **Emotion**: Cybernetic precision, nostalgic 80s arcade phosphor meets modern 120Hz micro-engineering, tactile digital craftsmanship.
- **Create this feeling through**:
  - Deep OLED obsidian canvas (`#08090b`) layered with microscopic subpixel grid coordinates (`rgba(255, 255, 255, 0.04)`).
  - High-voltage phosphor accents: Matrix Phosphor Lime (`#22c55e`), Electric Plasma Cyan (`#00f2fe`), and Solar Ember (`#ff4500`).
  - High-performance HTML5 Canvas bitmap raster engine: 9 distinct particle dissolution algorithms (Materialize, Signal, Typewriter, Dissolve, Rain, Radiate, Impulse, Glitch, Flow).
  - Interactive live typing terminal where users test custom strings, adjust pixel resolution, and test staggered wave directions.
  - Crisp typography: Heavy grotesque (`Syne` / `Plus Jakarta Sans`) paired with technical monospace instrumentation (`JetBrains Mono`).
