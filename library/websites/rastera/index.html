// ARCHITECTURE

Engineered for 120 FPS Subpixel Motion

Dual-Buffer Offscreen Raster

Text glyphs are painted once to an in-memory offscreen canvas buffer to extract subpixel alpha coordinates. Zero layout reflow or DOM tree recreation during particle updates.

3.1 kB Zero Dependencies

No heavy 3D runtimes or bloated WASM payloads. Pure deterministic Canvas 2D math running effortlessly at 60–120 FPS on all modern devices.

Full Accessibility Fallback

Automated screen-reader mirroring with invisible semantic HTML nodes. Honors prefers-reduced-motion by rendering instant crisp typography without flashing.

Component API & Integration

import { PixelReveal } from '@rastera/react';

export default function HeroHeader() {
  return (
    <PixelReveal
      text="RASTERA PRIMITIVES"
      preset="materialize"  // "signal" | "typewriter" | "dissolve" | "rain" ...
      pixelSize={5}
      duration={1.0}
      color="#22c55e"
      onComplete={() => console.log('Materialized')}
    />
  );
}
Prop Type Default Description
preset 'materialize' | 'signal' | 'typewriter' | 'dissolve' | 'rain' | 'radiate' | 'impulse' | 'glitch' | 'flow' 'materialize' Procedural particle dissolution mode.
text string Required The text string to rasterize and reveal.
pixelSize number 5 Grid resolution dimension in logical pixels (2–14).
duration number 1.0 Animation playback time in seconds.
color string '#22c55e' Hex or CSS color string for active phosphor particles.
trigger 'mount' | 'scroll' | 'hover' | 'manual' 'mount' Event trigger mode for starting the pixel reveal.
