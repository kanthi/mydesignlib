01 — CONTROL PRIMITIVES

Pause anything.
Approve in one call.

Three primitives cover every consequential action your agents take — money, access, and communication.

/ PAUSE

Halt on consequence

Policies decide which actions need a human. Everything else flows straight through — no latency where it doesn't matter.

client.policies.require(
  action="refund_customer",
  over=500,
  approver="finance-team")

/ APPROVE

Humans in one tap

Slack, email, or dashboard — approvers see the full context and decide in seconds, with an audit trail attached.

decision = client
  .approvals.request(
    action="refund_customer",
    amount=1200)

/ RESUME

Agents continue

The paused run resumes automatically with the verdict injected. Rejections branch to your fallback path.

if decision.approved:
  agent.resume(decision)
else:
  agent.escalate(decision)

04 — DOCS / FAQ

Asked by every team.

Does Vouch add latency to my agents?

Only to actions you flag as consequential. Everything else executes untouched. Approval routing typically resolves in under 900ms of human response ping — plus however long your approver takes to tap.

What happens if nobody approves?

Requests expire into the state you choose: hold, auto-reject, or escalate to a fallback channel. Expiry is a first-class policy, not an afterthought.

Where do approvals live?

Slack, email, and the dashboard out of the box. Every decision — approve, reject, or expire — is written to the immutable ledger with full context.

Is there a self-hosted option?

Scale-tier sample fiction aside, the template documents a single-tenant control plane with regional routing for regulated teams.
