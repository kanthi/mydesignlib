# MintQX — Website Design & Prompt Reference

## Prompt Concept
A futuristic neon fintech SaaS landing platform featuring framed headers, radiant colour fields, and a large interactive dual-mode dashboard mock. Responsive modular sections including bento features, how-it-works progression, telemetry metrics, security certifications, pricing toggles, and multi-theme presets (Mint, Violet, Ember).

## Visual Characteristics
- **Color Palette**: Void Black (#080C0A), Hyper Mint (#00FFB2), Electric Violet (#7B61FF), Pure Cream (#F6F5F2), Dark Carbon (#141C18).
- **Hero Staging**: Floating framed telemetry dashboard mock with live light/dark mode switcher, animated SVG line chart, counting metrics, and segmented controls.
- **Typography**: Instrument Sans (Display), Inter & Inter Tight (UI & Body).
- **Distinctive Elements**: Neon card pointer glow effects, interactive pricing billing cycle toggle, modular self-contained section blocks, fluid Lenis smooth scroll and GSAP scroll transitions.
