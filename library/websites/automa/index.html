FREQUENTLY ASKED QUESTIONS

Answers for Engineers

How does Automa guarantee sub-5ms workflow execution latency?
Automa utilizes an in-memory Rust event broker combined with WebAssembly (WASM) compute runtimes deployed across 45 edge regions. Workflows execute immediately adjacent to your incoming webhook ingress without spinning up heavy containers.
What happens when a downstream API (e.g. Stripe or Slack) experiences an outage?
Every step in an Automa pipeline is idempotent and backed by persistent distributed disk queues. If an endpoint errors, Automa executes an exponential backoff with jitter retry strategy, storing payload state safely until downstream connectivity recovers.
Can we write custom business logic inside workflow steps?
Yes. You can embed JavaScript, TypeScript, Python, or compiled WASM modules directly inside any node. Modules have access to cryptographic libraries, JSON transformations, and secure environment secrets.
