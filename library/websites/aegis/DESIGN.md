# Aegis AI — Design System

## Vision & Brand Identity
Aegis AI is an autonomous cybernetic agent defense and mission-critical hardware intelligence system. The design language features matte tactical dark black (#08080a), reflective chrome armor accents, high-intensity crimson visor red (#ff2a4b), and interactive terminal telemetry.

## Color Palette
- Background: `#08080a` (Matte Obsidian Black)
- Primary Accent: `#ff2a4b` (Visor Crimson Red)
- Secondary Glow: `rgba(255, 42, 75, 0.25)`
- Surface Card: `rgba(18, 18, 22, 0.8)` with `1px solid rgba(255, 42, 75, 0.2)`
- Text Primary: `#ffffff`
- Text Crimson Highlight: `linear-gradient(135deg, #ffffff 30%, #ff2a4b 100%)`
- Text Muted: `#8a8a9a`

## Typography
- Display / Headline: `Outfit`, `Space Grotesk`, sans-serif
- Monospace / Terminal: `JetBrains Mono`, `Fira Code`, monospace

## Core Layout & Components
1. **Tactical Header**: Air-gap status badge + floating menu.
2. **Hero Section**: Crimson gradient title "Intelligence that builds what's next", subtext, glowing crimson CTA button ("Book a Call ↗"), chrome cybernetic robot figure with glowing red visor.
3. **Trust Bar**: Partner logo wall.
4. **Interactive Command Center**: Live executable CLI terminal with real-time diagnostic output.
5. **Defense Matrix Bento**: Zero-trust guardrails, quantum cryptography, sub-5ms anomaly detection.
6. **SLA Pricing & Modal System**.
