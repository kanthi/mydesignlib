# Vesper.ai — Operational AI Infrastructure

A high-density, single-viewport dark landing page for **Vesper.ai**, an enterprise platform for training autonomous AI agents on enterprise workflows.

## Visual Direction & Aesthetics

- **Theme**: Pure black (`#000000`) monolith with subtle liquid-metal sheen, brushed metallic borders, and glassmorphism backdrop blurs.
- **Typography**:
  - Primary UI & Body: `Inter` variable sans-serif with subtle letter-spacing.
  - Accent / Hero Emphasis: `Instrument Serif` italic 400 (`#9a9a9a`) for editorial contrast (`Train <em>AI agents</em> on your workflows in minutes.`).
- **Layout Structure**:
  - Fixed-height single viewport (`100vh` / `100dvh`, `overflow: hidden`).
  - Full-bleed background video with delicate linear gradient vignette.
  - Liquid-metal pill floating navigation (Logomark, Links pill, Action CTA pill).
  - Bottom-centered hero lockup with badge, dual CTAs (liquid white shimmer & glass secondary).
  - Horizontal bottom metrics bar with custom SVG telemetry icons (Enterprise Mesh, Agent Telemetry, Sub-millisecond Execution).

## Key Features

1. **Liquid-Metal Nav & Buttons**: Custom specular gradient border reflections and hover sheen interactions.
2. **Autonomous Agent Telemetry Stats**: Three key operational metrics with live stat chips and inline SVGs.
3. **Responsive Adaptive Viewport**: Gracefully stacks on tablet and mobile viewports with an animated slide-down sheet navigation.
