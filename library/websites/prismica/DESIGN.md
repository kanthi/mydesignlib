# Prismica AI — Design System & Layout Architecture

Built and audited using the **L.I.F.T. Layout Framework** (Leverage, Internal Rhythm, Friction & Flow, Transferability).

## 1. Vision & Brand Identity
Prismica AI is an ultra-high-velocity spectral intelligence platform. The visual aesthetic fuses deep pitch-black space (`#06070a`), luminous chromatic light dispersion gradients, razor-sharp hairline grids with crosshair coordinates, and frosted glass telemetry cards.

## 2. Color System
- **Background Root**: `#06070a` (Deep Void Pitch Black)
- **Background Surface**: `rgba(255, 255, 255, 0.025)`
- **Glass Border**: `rgba(255, 255, 255, 0.08)`
- **Glass Border Hover**: `rgba(255, 255, 255, 0.28)`
- **Spectral Prism Gradient**: `linear-gradient(135deg, #ff3366 0%, #ff9900 25%, #ffd700 45%, #00ff88 65%, #00bfff 85%, #8a2be2 100%)`
- **Text Primary**: `#f2f4f8`
- **Text Secondary**: `#a1a9be`
- **Text Muted / Telemetry**: `#636c84`

## 3. Typography & Mathematical Rhythm
- **Display / Hero Titles**: `Syne`, sans-serif (800 weight with tight -0.04em tracking)
- **Section Headers**: `Syne`, sans-serif (700 weight)
- **Body Copy**: `Plus Jakarta Sans`, sans-serif (400 / 500 weight, 1.75 line-height)
- **Technical Telemetry / Code**: `JetBrains Mono`, monospace

## 4. L.I.F.T. Layout Execution
- **L (Leverage Point)**: Centered-asymmetric hero headline commanding immediate focal dominance, flanked by live spectral particle beacon and fluid CTA cluster.
- **I (Internal Rhythm)**: Strict 12-column compound grid with 8px baseline rhythm (`8px`, `16px`, `24px`, `32px`, `48px`, `64px`, `96px`). Eye choreography smoothly transitions from Hero $\to$ Trust Node Ticker $\to$ Compound Bento Matrix $\to$ Interactive Dispersion Sandbox $\to$ Benchmark Matrix $\to$ Pricing Tiers.
- **F (Friction & Flow)**: Tactical friction via chromatic aberration borders, mono telemetry tags (`[λ = 432nm]`), and live interactive canvas dispersion physics; balanced by expansive white space flow and ultra-clean reading zones.
- **T (Transferability)**: Fluid responsive layouts via CSS `clamp()` and container queries, tested across mobile ($375\text{px}$), laptop ($1280\text{px}$), and ultra-wide screens ($5\text{K}$).
