# FolioCraft — Website Design & Prompt Reference

## Prompt Concept
A high-converting, radiant SaaS landing page for an AI-powered resume and career dossier builder named "FolioCraft". Fused with clean typography, abundant white space, warm solar coral/peach accents, and an intricate product-as-proof hero composition.

## Visual Characteristics
- **Color Palette**: Solar Coral (#FF5B1B), Radiant Tangerine (#FF7A33), Diffused Coral Glow (rgba(255, 91, 27, 0.35)), Soft Peach Skeleton Tint (#FFEFE7), Obsidian Ink (#111417), Pure Canvas White (#FFFFFF).
- **Hero Staging**: Layered visual proof stack with glowing concentric orbital rings, circular avatar focal point, browser frame document builder with pastel window controls, floating "Applied Resumes - 12 Interviews" bar chart card, and interactive AI prompt pill.
- **Typography**: Plus Jakarta Sans (Display), Inter (Interface & Copy), JetBrains Mono (Telemetry & Metrics).
- **Distinctive Elements**: Subtle vertical column background grid guidelines, floating glassmorphic pill navbar, live interactive template switcher, ATS score simulator widget, and crisp monochrome partner strip (Synergy, Horizon, Catalyst, Phoenix, Pulse, Solaris, Aurora).
