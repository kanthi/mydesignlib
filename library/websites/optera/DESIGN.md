# DESIGN — Optera (Intelligent Business Automation & AI Operations)

## Overview
- **Audience**: Enterprise founders, COOs, heads of operations, and workflow architects automating mission-critical business processes.
- **Single CTA**: `Book a Strategy Call` (with secondary `Get Started ↗` / `Book a Demo ↗`).
- **Emotion**: Ruthless architectural competence, cybernetic momentum, executive clarity, zero wasted motion.
- **Create this feeling through**:
  - Pure void black backdrop (`#07080a`) with hairline telemetry grids (`rgba(255, 255, 255, 0.08)`).
  - High-voltage kinetic cyan-to-lime gradient accents (`linear-gradient(90deg, #00d2ff 0%, #a6ff00 100%)`).
  - Indexed monospace telemetry tags (`[ 02 / 11 ] • WHO WE ARE`, `[ 05 / 11 ] • PROCESS`).
  - Interactive automation pipeline mockup with live execution nodes and real-time activity log.
  - Video showreel modal, interactive 4-step methodology cards, and transparent pricing sprints.

## Source of truth
- This file + CSS `:root` in `index.html`.

## Aesthetic commitment
- **Name**: Cybernetic High-Conviction Agency
- **Signature element**: Kinetic Cyan-to-Lime gradient pill action triggers with indexed bracket telemetry notation (`[ 01 / 11 ]`).

## Colors (semantic)
- `bg-dark`: `#07080a` — Deepest void black
- `surface-dark`: `#0e1014` — Secondary background tier
- `surface-card`: `#13161c` — Elevated card surface
- `surface-border`: `rgba(255, 255, 255, 0.08)` — Hairline border lines
- `surface-border-hover`: `rgba(255, 255, 255, 0.18)` — Hover borders
- `text-primary`: `#ffffff` — Crisp pure white headlines
- `text-secondary`: `#94a3b8` — Slate gray for explanatory copy
- `text-muted`: `#64748b` — Subtle labels and metadata
- `accent-gradient`: `linear-gradient(90deg, #00d2ff 0%, #a6ff00 100%)` — High-voltage gradient
- `accent-cyan`: `#00d2ff` — Primary electric blue
- `accent-lime`: `#a6ff00` — High-visibility acid lime

## Typography
- **Display**: `Plus Jakarta Sans`, sans-serif (Weights: 600, 700, 800) — Headings, punchy statements
- **Body**: `Inter`, sans-serif (Weights: 400, 500, 600) — Descriptions, testimonials, specs
- **Mono / Index**: `JetBrains Mono`, monospace (Weights: 500, 700) — `[ 02 / 11 ]` badges, metrics, status logs
- **Scale**:
  - Hero display: `clamp(2.75rem, 5.2vw, 4.4rem)` (leading: 1.08, tracking: -0.035em)
  - Section title: `clamp(2.0rem, 3.8vw, 3.0rem)` (leading: 1.15, tracking: -0.025em)
  - Body: `1.0rem` (leading: 1.6)
