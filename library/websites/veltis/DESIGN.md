# Veltis — Design System & Visual Specification

## 1. Brand Concept & Positioning
- **Name**: Veltis (Fictional rebrand from reference Apptics by @jaydwivedi_)
- **Category**: SaaS / Ecommerce Infrastructure & Scaling Engine
- **Tagline**: The Complete Ecommerce Engine — Everything you need to scale from subscriptions to fulfillment, all under one roof.
- **Tone**: Hyper-clean, luminous, high-velocity SaaS with soft frosted glass, iridescent chromatic highlights, crisp typography, and high-conversion structural rhythm.

## 2. Color Palette & Lighting
- **Canvas Base**: `#FAFAFC` / `#FFFFFF` (pure clean daylight)
- **Primary Brand**: `#4F46E5` / `#4338CA` (deep royal indigo with violet gradient)
- **Accent Chromatic**:
  - Cyan: `#06B6D4` / `#22D3EE` (CRM & telemetry)
  - Emerald: `#10B981` / `#059669` (Payments & approvals)
  - Amber / Tangerine: `#F59E0B` / `#D97706` (Chargebacks & alerts)
  - Magenta: `#EC4899` / `#DB2777` (Creatives & media)
  - Purple / Violet: `#8B5CF6` / `#7C3AED` (Education & mastery)
- **Ink & Contrast**:
  - Headline Primary: `#0F172A` (deep slate black)
  - Body Copy: `#475569` (slate grey)
  - Border / Glass Rule: `rgba(15, 23, 42, 0.08)`
  - Card Surface: `#FFFFFF` with `box-shadow: 0 10px 30px -5px rgba(0, 0, 0, 0.04), 0 20px 40px -15px rgba(0, 0, 0, 0.06)`

## 3. Typography Stack
- **Display & Headlines**: `Plus Jakarta Sans`, 700 / 800 / 900, tight negative tracking (-0.035em)
- **Body & Controls**: `Inter`, 400 / 500 / 600
- **Telemetry & Badges**: `JetBrains Mono`, 600

## 4. Key Visual Devices
1. **Iridescent 3D Prism Hero**: Floating perspective grid with soft drop shadows and luminous translucent glass slab reflecting violet-cyan ambient light.
2. **Modular Micro-Stat Cards**: 4-card grid alongside each primary feature module, featuring rounded badge icons and clean metric labels.
3. **Interactive UI Demonstrators**:
   - Live MRR subscription simulator.
   - High-risk payment card visualizer.
   - Interactive split-slider for mobile theme comparison.
   - Interactive global logistics tracker.
4. **Isometric Icon Constellation**: End-of-page interactive 3D constellation of glowing service icons floating above a perspective grid.
