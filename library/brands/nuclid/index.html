Nuclid

Mark

Three orbits. One hex core.

NCL-3: ellipses at 0°, 60°, and 120° around CORE-HEX. Clear space is one cap-height of the N. Never fill the orbits into clover lobes.

Orbits

Three strokes, never filled. Ratio 22 : 8.5 in a 64 unit box. Code NCL-3.

Nucleus

Pointy hex, radius 5. Not a circle, not a rounded square. Code CORE-HEX.

Beads

One electron per orbit. Do not add a fourth. Do not drop them in lockups under 16px.

Color

Mint or forest. Teal is a bar.

One light field. One dark field. Teal never becomes a second lockup.

Applications

Voice

Nucleus. Orbit. Isolate.

Lab

Say nucleus, orbit, isolate, core. Do not say platform, stack, or suite.

Short

One clause. If it needs a comma, it needs a diagram instead.

Held

The identity is an object. Write as if the token is already in the hand.

Rules

Do

  • Set the mark in charcoal on mint, or mint on forest.
  • Keep the hex nucleus. Three orbits, three beads.
  • Composite the mark onto glass in code, not in the photograph.
  • Use Manrope sentence-case for Nuclid.

Don’t

  • Fill the orbits into a three-lobe clover.
  • Rotate the mark in a lockup.
  • Set mint type on teal, or charcoal type on forest.
  • Bleed teal as a second lockup field.
