Usage

Do and don’t

Do

  • Use the peak mark in charcoal, rust, sage, or cream
  • Keep photography in the gold-hour / teal grade
  • Set lockups in Sora, all caps, with the plate
  • Reserve signal green for the pip

Don’t

  • Cite Supahumans or real ATS / hiring trademarks
  • Redraw the peak as an arrow or a U
  • Put signal green on cream as body type
  • Use Inter, purple fields, or stock “team smiling at a laptop”
