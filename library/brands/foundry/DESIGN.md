# Foundry — Brand Identity & Developer System Specification

## 1. Brand Essence & Positioning
- **Brand Name**: Foundry (`Foundry`)
- **Category**: AI Infrastructure / Developer SDK / Tooling
- **Tagline**: *Ship AI features without the infra headache.*
- **Core Value Proposition**: One SDK, zero plumbing. Standardizing vector routing, model caching, and fallback pipelines into a single developer-first primitive.

---

## 2. Logo Mark & Geometric Construction
- **Symbol Concept**: An architectural, chiseled geometric anvil and stylized letterform `F`.
- **Anatomy**:
  - Upper Cantilever: Projecting forward horizontal beam with a clean 45-degree bevel, symbolizing forward engineering velocity.
  - Lower Horn: Stepped diagonal wing anchoring the foundation, symbolizing rock-solid infrastructure.
  - Counter Notch: Mechanical center punch providing internal optical breathing room.
- **Clear Space**: Minimum $1.5\times$ unit padding based on the vertical stem height.

---

## 3. Typographic System
- **Brand Display & Wordmark**: `Space Grotesk`, 700 / 600 weight. A proportional sans-serif with idiosyncratic technical details and geometric quirks that convey modern developer ergonomics.
- **Body & Marketing Copy**: `Inter`, 400 / 500 weight, balanced line-height `1.6`.
- **Code & Command Snippets**: `JetBrains Mono`, 500 weight, clean monospace syntax formatting.

---

## 4. Color Palette Tokens
| Token | Hex | Role | Contrast vs White |
|---|---|---|---|
| **Ink** | `#111111` | Primary text, dark cards, terminal surfaces | 16.5:1 |
| **Canvas** | `#FFFFFF` | Light card surfaces, clean paper | 1.0:1 |
| **Cobalt** | `#1A1D7C` | Master identity card, SDK primary badge | 10.8:1 |
| **Electric Indigo** | `#6366F1` | Interactive states, SDK tokens, active pills | 4.8:1 |
| **Cyan** | `#22D3EE` | Terminal highlights, vector pipeline pulses | 1.4:1 (on dark) |

---

## 5. Compositional Brand Board Architecture
The identity specimen recreates the exact 4-quadrant developer board:
1. **Quadrant 1 (Top Left)**: Hero Master Lockup card with oversized chiseled mark.
2. **Quadrant 2 (Top Right)**: Hero Value Proposition card (*Ship AI features without the infra headache*) + Interactive SDK Terminal (`import { Foundry } from '@foundry/ai'`) + Pill Badge (*Introducing Foundry. One SDK, Zero Plumbing.*).
3. **Quadrant 3 (Bottom Left)**: Brand Identity Surface in deep ultramarine cobalt (`#1A1D7C`) displaying color swatch tokens and lockup variants (icon mark, squircle app icon, circular emblem).
4. **Quadrant 4 (Bottom Right)**: Space Grotesk typographic specimen sheet with character set matrix and live font tester.
