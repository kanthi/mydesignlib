# DESIGN — Lumenport

## Overview
- Audience: Mid-market importers, freight forwarders, trade ops leads
- Single job: Communicate a complete visual identity (mark, type, color, applications)
- Emotion: Clear, confident, maritime logistics
- Create this feeling through:
  - Deep ocean blues + signal gold (not purple SaaS)
  - Geometric path mark (original L-route, not Vertimport)
  - Space Grotesk wordmark, tight tracking
  - 2×3 application board + expanded system rules

## Aesthetic commitment
- Name: Maritime trade signal
- Signature element: L-route mark with square node (port beacon / path)

## Colors (semantic)
| Token | Hex | Use |
|-------|-----|-----|
| navy-deep | `#014A73` | Primary field, wordmark reverse |
| navy | `#165672` | Surfaces, tags |
| ocean | `#2B6377` | Mid surfaces |
| steel | `#3C7382` | Secondary UI, pattern base |
| gold | `#D89A00` | Primary mark on navy, accents |
| gold-bright | `#F3B200` | Fields, highlights |

## Typography
- Display / wordmark: Space Grotesk 600–700, tracking −0.02em
- Body: Plus Jakarta Sans 400–500
- Labels: 0.72–0.8rem uppercase, letter-spacing 0.1em

## Mark
- Geometric L-route: vertical stem → diagonal path → square node (SVG only)
- Clear space: 0.5× mark height on all sides
- Min size: 24px digital, 12mm print

## Components (specimen)
- Primary lockup (mark + wordmark)
- Construction grid
- Color ramp
- Applications: tote, tablet, hang tags
- Pattern: staggered + nodes (from mark language)

## Ban list
- Vertimport / real logistics brands
- Inter, purple gradients, emoji icons
- Stretching the mark, recoloring gold to multicolor gradients

## Accessibility
- Gold on navy and navy on gold meet large-text contrast
- Focus-visible rings on interactive nav
