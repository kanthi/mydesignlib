# DESIGN — Critelo

## Overview
- Audience: Product designers, brand designers, design leads
- Product: AI that critiques creative work (logos, sites, identity, posters)
- Emotion: Honest, sharp, optimistic — “critique, not compliments”
- Create this feeling through:
  - Blue → coral fingerprint field (signal + warmth)
  - Geometric frame mark (original, not Thesis triangle)
  - Clean paper sections + soft social cards
  - Process: Upload → Analyze → Improve → Repeat

## Aesthetic commitment
- Name: Soft-signal design tech
- Signature: Contour texture field + framed mark + dual social cards

## Colors
| Role | Hex |
|------|-----|
| coral-50–900 | `#FFF1EC` → `#3D1A12` |
| paper | `#FFFFFF` / `#F7F8FA` |
| blue-50–900 | `#EAF2FF` → `#0B1F4A` |
| ink / slate | `#0F1419` → `#8B939E` |

Primary UI blue: `#3D8BFF` · Accent coral: `#FF7A59`

## Typography
- Display / wordmark: Plus Jakarta Sans 700–800, tracking −0.03em
- Body: Plus Jakarta Sans 400–500
- Labels: 0.7–0.75rem uppercase, wide tracking

## Mark
- Rounded square frame + internal chevron/path (critique lens)
- Clear space ≥ 0.5× mark height
- On blue/coral fields: white mark; on paper: blue mark

## Ban
- Thesis / real AI design-critique brands
- Inter as display, purple mesh SaaS defaults
- Stretching the mark; multicolor fills on the mark
