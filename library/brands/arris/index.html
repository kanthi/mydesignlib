Mark

A ridge, not a letter.

Two planes meeting. Clear space is one cap-height of the word. Never add a drop shadow, never rotate, never set in mid-grey.

Color

Crimson or black. Not both as fill.

One saturated field. The rest of the kit is ink, charcoal, and paper.

Voice

Name the joint.

Specific

Say coping, arris, and soffit. Do not say “solutions for the built environment.”

Short

One clause. If it needs a comma, it needs a drawing instead.

Civic

Written for the person on the pavement, not the pitch deck.

Rules

Do

  • Set the ridge in white on crimson, or crimson on paper.
  • Keep the cube sign: one face mark, one face arrow.
  • Use true black for long text on paper.

Don’t

  • Outline the ridge in grey or add a glow.
  • Set crimson type on black.
  • Replace the ridge with a letter A.
