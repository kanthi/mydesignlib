Voice

How Helikon speaks

Human first. Specific over grand. Heritage as method, not costume.

Human first

The model drafts. The studio signs. Never let a tool become the voice in the room.

Specific

Name the plate, the cloth, the cut. Skip seamless, unleash, and next-gen.

Lasting

Write as if the line will be cut in stone. Short theses. No costume antiquity.

Meander frame

The Greek key is structure, not garnish. Run it as a top and bottom band on crimson, gold, and parchment fields. Gold stroke on smoke. Never rainbow.

Usage

Do and don’t

Do

  • Set the wordmark in Oswald, all caps, with the ®
  • Frame color fields with the meander, not a drop shadow
  • Keep ember as a tile in the four-block palette
  • Use engraving on smoke and oil studies on parchment
  • Leave clear space ≥ 0.5× the gate height

Don’t

  • Stretch the wordmark or outline it in gold gradients
  • Place crimson type on ember or gold type on gold
  • Use Inter, purple fields, or emoji as marks
  • Fill a page with ember or turn the meander into a rainbow
  • Cite real studios, designer handles, or client trademarks
