# Caucus

Identity study for a fictional mediation room. The wordmark is CAUCUS. The domain line is caucus.law. Mail is desk@caucus.example, as a mailto link only.

Caddy path: `library/brands/caucus/`

## Tree

- `index.html` — hub. Group A is the replica. Group B is the extended system.
- `preview.jpg` — board thumbnail, 1600 × 900
- `prompt.md` — palette, type, and deliverables
- `DESIGN.md` — board rules
- `css/tokens.css` — colour tokens. The replica also carries Vellum and Brine presets.
- `js/brand-config.js` — names, domain, and mail for those replica themes
- `assets/` — mark and favicon
- `replica/` — six-card board (`index.html`, `styles.css`), SVG marks, `exports/board.png`, `exports/compare.png`
- `extended/` — `shared.css`, guidelines, landing, social kit, merch, email signature, logo reveal, vendored GSAP, and one PNG per extended hub card

The theme switcher sits on the replica only. Extended pages use the Caucus palette.
