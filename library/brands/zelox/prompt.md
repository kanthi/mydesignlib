# Zelox Brand System — Generative & Reference Prompt

## Prompt Concept
An expansive, tactile brand identity system for a premier custom software and engineering firm named "Zelox".

## Visual Characteristics
- **Color Palette**: Electric Iris Purple (#7367FF), Soft Iris Highlight (#988FFF), Deep Obsidian (#08070F), Pure White (#FFFFFF).
- **Emblem**: Centrosymmetric kinetic Z-ribbon glyph with opposing triangular arrowheads.
- **Aesthetic**: Modern tech engineering, tactile flatlay presentation, physical stationery suite (notebooks, holographic cards, lanyard badges), architectural billboard, apparel specimens, and crisp typography (Space Grotesk + Plus Jakarta Sans).
