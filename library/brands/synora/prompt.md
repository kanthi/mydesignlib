# Synora Brand System — Generative & Reference Prompt

## Prompt Concept
A comprehensive, ultra-modern brand identity system for an enterprise AI workflow automation platform named "Synora". 

## Visual Characteristics
- **Color Palette**: Deep Obsidian (#05060A), Electric Signal Cobalt (#1958EC), Cobalt Bright (#3D73FA), Crisp White (#FFFFFF).
- **Emblem**: Minimalist geometric convergence glyph formed by four interlocking angled brackets meeting at a diamond core.
- **Aesthetic**: Architectural precision, quiet luxury technology, diffuse ambient cobalt lighting, editorial poster layouts with crisp typography (Syne + Inter).
- **Mockup Touchpoints**: Three editorial posters (minimal pill badge card, blurred cobalt silhouette poster, pattern matrix card), SaaS web app UI frame, and an urban highway transit lightbox billboard.
