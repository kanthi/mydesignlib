# Reyla Brand System — Generative & Reference Prompt

## Prompt Concept
A comprehensive, ultra-refined brand identity system for a premier digital design studio and web architecture brand named "Reyla".

## Visual Characteristics
- **Color Palette**: Deep Burgundy (#24070B), Fiery Vermilion (#E64415), Bright Flame (#FA6B38), Ice Sky (#E8F0FE), Studio Cream (#EDECE8).
- **Emblem**: Modular 3-tier stepped geometric emblem consisting of an inverted top L-bracket, middle horizontal bar, and bottom-right anchor square separated by a uniform negative space channel.
- **Aesthetic**: Modern high-end studio presentation monitor deck, 16 modular slides (4x4 grid), "Layer by Layer" and "Built to stand above" editorial typography (Plus Jakarta Sans), diffuse warm flame lighting, and clean vector design tokens.
