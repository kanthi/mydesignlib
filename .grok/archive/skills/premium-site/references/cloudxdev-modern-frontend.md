## Philosophy

Every interface tells a story. Before code:

1. **Context** — problem, user, emotion  
2. **Concept** — core metaphor  
3. **Commitment** — one bold direction, executed throughout  

## Phase 1 — Choose ONE aesthetic

Examples from skill: Neo-Brutalist, Soft Minimalism, Retro-Futuristic, Editorial/Magazine, Organic/Natural, Glass Morphism, Maximalist Chaos, Art Deco, Memphis, Swiss, Dark Academia, Y2K, Custom Hybrid.

Pick one (or hybrid of 2 max). Do not average styles.

## Phase 2 — Tokens before code

Define CSS custom properties: type scale, space unit, colors, animation easing — **then** implement.

Never Inter/Roboto as display. Intentional pairings only.

## Phase 3 — Layout

Break the grid intentionally (asymmetric columns, overlapping visual/content). Centered cookie-cutter heroes are the default failure mode.

## Phase 4 — Motion

One orchestrated entrance beats scattered micro-interactions. Scroll via Intersection Observer. Hover with restraint.

## AI Look checklist (NEVER stack these)

- Purple/blue gradient backgrounds  
- Inter or system fonts  
- Centered hero with subheading  
- 3-column feature cards  
- Rounded corners on everything  
- Drop shadows on all cards  
- `#6366F1` as primary  
- 16px border radius everywhere  
- “Modern / Clean / Simple” as only descriptors  

## Pitfalls

Over-animation · Timid choices · Mismatched complexity · Context ignorance · Trend chasing (glass everywhere = new purple gradient)

## Quality checklist (abbreviated)

- Clear point of view; memorable tomorrow  
- Avoids generic AI patterns  
- Responsive + accessible  
- Custom focus, loading/error states  
- Consistent type hierarchy
