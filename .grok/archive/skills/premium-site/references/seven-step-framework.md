# 7-step prompt framework (website elevation)

Source: https://x.com/Info_sam_ai/status/2082792966587109683  
(Same outline reposted by multiple accounts; treat as community pattern, not exclusive IP.)

## Steps

01. **Signature Blueprint** — Strategy before design (audience, one job, one CTA, signature idea).  
02. **Anti-Sameness Type** — Distinctive typography system (not Inter-as-display).  
03. **Breathing Room Audit** — Spacing and visual rhythm only.  
04. **Purposeful Motion** — Polish without gimmicks (200–300ms, no bounce).  
05. **Case Study Framer** — Present work like a high-end studio (editorial case bands, not 4 equal cards).  
06. **Trust Signal Sweep** — Remove amateur credibility gaps (fake stock, vague claims, broken contact, emoji icons).  
07. **Reference Anchor** — Unique direction without copying layouts.
