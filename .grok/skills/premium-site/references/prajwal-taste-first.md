## Thesis

Same model + same brief can produce purple AI template **or** studio-quality page.  
The model has no taste; prompters who type “make it more premium” are starving it.

**Stop blaming the AI for ugly code. Upgrade what you feed it.**

## 3-step workflow (from posts)

1. **Cultivate taste first**  
   Collect real references (screenshots, live sites, mood). Adjectives (“premium”, “clean”) fail.

2. **Give Claude the right tools**  
   Design skills, design system tokens, ban lists — not vibes.

3. **Build the right way**  
   Order that works (from May 2026 workflow post):  
   - Set up a **design system**  
   - Create a **template** / structure  
   - Build a **skill** that encodes it  
   - Generate in one shot  

Most people skip the first three steps and wonder why output looks like trash.

## Demo claims (posts)

- Startup landing built twice: dark-purple AI template vs design-studio look.  
- Car brand landing: cartoon CSS car + lime buttons vs golden-hour campaign hero.  
- Agency-tested on fictional AI infra company end-to-end.

## Repo adaptation

- Use `design-system-first` before writing `index.html`.  
- Never rely on “make it more premium” as a polish pass.  
- Version upgrades: feed v1 the **design system + ban list**, not just “improve atrium”.
